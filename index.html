Personal Hardware IDS/SIEM

PiSec Lab

Built a Raspberry Pi-based IDS/SIEM home lab where the Pi creates a local Wi-Fi network and client devices connect through it. Network traffic is captured with tcpdump, completed PCAP files are moved into an IDS input folder, and an IDS watcher analyzes them for suspicious activity. Alerts are written to alerts.jsonl, displayed in a dashboard, and processed PCAP files are moved to an archive or deleted after successful ingestion.

At the core of the lab are 16 custom YAML detection rules covering port and service scans (SSH, RDP, SMB, Telnet, ADB, Docker API, and router admin ports), volumetric anomalies (SYN, ICMP, and TCP reset spikes), DNS-based threats (dynamic DNS, tunneling and remote-access services like ngrok, and NXDOMAIN spikes), and large outbound transfers that can signal exfiltration. Each rule is tuned with thresholds, time windows, cooldowns, per-device multipliers, and trusted-device weighting, so known hosts trigger fewer false positives while suspicious behavior still raises alerts.

The dashboard supports alert review, searchable SIEM metadata, custom IDS rule creation, and basic firewall rule creation. A SIEM ingest pipeline extracts flow, DNS, device, and traffic metadata from PCAPs and stores it in SQLite. I also used Tailscale to access the dashboard through a private network instead of exposing it publicly.

iOS App Swift, Claude API, Firebase

AI Fitness & Nutrition Tracker

Built an iOS app to track my meals and workouts, powered by the Anthropic Claude API. I log a meal by listing its ingredients and how it was prepared, and the app uses the Claude model to estimate calories and generate personalized workouts that adapt over time. All data — what I ate and which exercises felt hard — is stored in Firebase, so recommendations get more accurate and stay aligned with foods I like but keep healthy.

The app has its own habit-scoring system: healthy choices earn points and unhealthy ones lose them. Using Google APIs, Core Location, and device sensors, it applies geofencing — if I get too close to a fast-food location it deducts points, and it identifies gym locations to gate a daily fitness challenge that I have to complete on-site before leaving without losing points.
